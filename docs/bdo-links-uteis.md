Os 12 endereços que já tínhamos formalmente registrados no projeto são BDOLytics, BDO Codex, Garmoth, KorBDO, Workerman, Velia Inn Developers, Black Desert Market API, `bdomarket`, BDO Market API/Postman, o Swagger `test-bdo.mos.gov.pl`, Garmoth Tools e BDO Alerts.

Para montar uma base própria, eu dividiria as fontes assim: **BDO Codex + extractor para conteúdo estático**, **Velia Inn/BlackDesertMarket/Arsha para mercado**, **Workerman para nodes/workers/CP**, **Garmoth/BDOLytics para validação e ferramentas**, e **site oficial para PT-BR, quests, eventos e mudanças recentes**. O extractor não substitui o mercado atual porque preço do Mercado Central é server-side; nosso levantamento também identificou drop rate real e alguns yields exatos como dados que não vêm integralmente do cliente.
